## 💼 Featured Case Studies & Projects

### 1. 🏢 Enterprise ERP & Operations Dashboard
- **Stack:** React, Node.js, Express, PostgreSQL, TailwindCSS, Docker
- **Summary:** An enterprise resource planning platform designed for travel & tourism operations in Kigali. Automates customer booking schedules, quotation workflows, client ticketing, and role-based staff administration.
- **Key Result:** 45% reduction in booking turnaround time and 100% booking data consistency.

### 2. 🌐 Multi-VLAN Corporate Infrastructure & Router-on-a-Stick
- **Stack:** Cisco IOS, Catalyst Switches, Cisco Routers, 802.1Q Trunking, Packet Tracer
- **Summary:** Enterprise-grade network architecture separating Layer 2 broadcast domains (Staff, Management, and Guest Wi-Fi) with 802.1Q trunking and Layer 3 router subinterfaces.
- **Key Result:** Zero broadcast leakage across departmental subnets and robust perimeter security.

### 3. 🚢 Containerized Microservices & CI/CD Pipeline
- **Stack:** Docker, GitHub Actions, Nginx Reverse Proxy, Ubuntu Linux, SSL/TLS
- **Summary:** End-to-end continuous deployment automation featuring Docker multi-stage builds, automated unit/integration test suites on PR merge, and zero-downtime Nginx reverse proxy routing.
- **Key Result:** 60% smaller container images and seamless hands-off production releases.

### 4. 💳 Secure FinTech Payment Gateway & Webhook Engine
- **Stack:** Node.js, Express, Redis, MTN Mobile Money API, Airtel Money, Webhooks
- **Summary:** High-reliability payment integration module for East African telecom APIs and card processors with SHA256 HMAC cryptographic signature validation and idempotent retry workers.
- **Key Result:** 99.96% webhook delivery success and zero double-charge incidents under high concurrency.

## 💻 Local Development Setup

To inspect or run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Inganji-clovis/inganji-clovis-portfolio.git
   cd inganji-clovis-portfolio
   ```

2. **Serve the project:**
   You can open `index.html` directly in any web browser, or launch a local static server:
   ```bash
   # Using Python 3:
   python -m http.server 8080

   # Or using Node.js npx:
   npx serve .
   ```

3. **View in browser:**
   Open [http://localhost:8080](http://localhost:8080) to explore the site.

## 🚢 Deployment

### Deploying to GitHub Pages (Automated):
1. Navigate to **Settings** > **Pages** in this GitHub repository.
2. Under **Build and deployment** > **Source**, choose `Deploy from a branch`.
3. Select `main` branch and folder `/ (root)`, then click **Save**.
4. Your portfolio will be live at `https://inganji-clovis.github.io/inganji-clovis-portfolio/`.

### Deploying to Vercel:
```bash
npm install -g vercel
vercel
```
